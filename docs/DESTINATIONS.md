# Destinations — complete release registration map

The source has 74 registered services plus two enum-level FileUploader delegation routes. Every row below is in scope. “Registered” means present in source, not currently reachable or authorized. Providers can expose multiple operations/settings inside one service. Their full configuration fields remain in the settings index.

## Shared adapter contract

Extract source request/auth/signing/result code from WinForms configuration/UI types. Preserve every referenced UploadersConfig field, provider options, progress/cancel/retry behavior, response errors, link/thumbnail/deletion outputs, and any provider-specific encryption. Replace icons/dialogs/credentials/platform helpers. Fixture the actual request and response semantics at a local endpoint, then validate live operation separately with an authorized account and synthetic file. For sharing services, preserve source URL-template versus API behavior; do not turn every service into an upload.
